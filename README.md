# 蛋注音 EggIME — 實驗測試版

**目前仍在實驗與測試，這不是正式版。** 功能、操作及資料格式可能調整，尚未完成全面的相容性與長期穩定性驗證。

## 下載

請至 [Releases](https://github.com/J030104/EggIME/releases) 下載 **v0.1.0-alpha.3** 的 `EggIME-0.1.0-alpha.3-macOS-arm64.zip`，並以同頁的 `SHA256SUMS.txt` 核對下載檔案。GitHub 自動產生的 Source code ZIP 僅包含此發佈頁面的文件，並非可建置的應用程式原始碼。

此測試包基於應用程式版本 **0.1.0 / build 2026110601**，提供 Apple silicon 成品。隨附本機 AI runtime 需要 **macOS 26 以上**；Intel 與較舊系統未驗證。程式使用本機 ad-hoc 簽章，**沒有 Apple Developer ID 簽章或 Apple 公證**，macOS 可能阻擋開啟。

## 本次更新

v0.1.0-alpha.3 修正連打「等等」時，第二個 `/` 讓注音被誤判為數字的問題。標準大千鍵位 `2/32/3` 可正常送出「等等」。

## 安裝與試用

1. 解壓縮下載檔。若已有蛋注音正在執行，先切換其他輸入法並結束蛋注音。
2. 在終端機執行解壓縮資料夾內的 `install.command`，也可在 Finder 按兩下執行。安裝至 `~/Library/Input Methods/EggIME.app`；更新時會備份既有蛋注音。
3. 從輸入來源選單選「蛋注音」。若尚未顯示，重新登入，再至「系統設定 → 鍵盤 → 輸入方式」加入。

如系統阻擋，請先確認下載來源與 SHA-256，再依 macOS 顯示的提示處理。

可先開啟獨立試打視窗：`open EggIME.app --args --demo`。試打視窗不能代表所有 App 的系統輸入法行為。

## 主要操作

- 標準大千注音輸入；Enter 送出組字，↓ 開中文候選。
- 英文輸入後 Tab 接受補全；左右鍵與退格編輯組字。
- Shift＋逗號／句點輸出「，」「。」。
- 從輸入法選單開啟偏好設定。
- 中英／數字交界自動空格、英文補全後自動空格，兩項均預設關閉。

## 測試範圍與已知限制

- build 2026110601 的 109 項自動化測試通過，包含「等等」、斜線日期及版本號。此版驗證範圍為輸入核心與發佈包自我檢查。
- 歷史原生測試包含 build 2026110211 的「已安裝」修正，以及 build 2026110210 的 50＋8 句與 26 個標點案例。
- 剛啟用輸入來源後曾出現英文字母直接送出的情況，仍待調查。
- 同音字可能需要選字；其他 App、候選視窗各種配置及長時間穩定性尚未全面驗證。
- 發佈包沿用 alpha.2 的詞庫、模型及本機 AI 執行環境。

回報問題時，請提供 macOS 版本、App 名稱、操作步驟、預期與實際結果；避免附上私人輸入內容。

## 資料與移除

設定與個人詞彙保存在 `~/Library/Application Support/EggIME/`。移除前先切換其他輸入法，於鍵盤設定移除蛋注音，再將 `~/Library/Input Methods/EggIME.app` 移至垃圾桶。使用者資料保留，可自行備份或移除。
